# Code of Conduct

This project is for building useful, privacy-respecting AI agent tooling.

Expected behavior:

- Be respectful and direct.
- Assume good intent, but correct problems clearly.
- Keep discussions focused on the project and its users.
- Do not post private messages, personal voice samples, credentials, or company
  data in public issues or pull requests.
- Do not use this project to impersonate another person or hide authorship where
  disclosure is required.

Unacceptable behavior includes harassment, threats, doxxing, spam, and sharing
private data without permission.

Report conduct or privacy issues privately to the maintainer. Security and
privacy reports should follow [SECURITY.md](SECURITY.md).
