# Homebrew packaging

This directory contains the Homebrew packaging proof and public tap formula
template for `voice-layer`.

## Local test

Homebrew 5 requires formulas to live in a tap. Build the local source archive
from a committed git tree, not from the working directory:

```sh
python3 scripts/validate_release_archive.py --output packaging/homebrew/dist/voice-layer-0.1.0.tar
gzip -n -f packaging/homebrew/dist/voice-layer-0.1.0.tar

TAP_DIR="$(brew --repository)/Library/Taps/voice-layer/homebrew-local"
mkdir -p "$TAP_DIR/Formula"
git -C "$TAP_DIR" init
ln -sf "$PWD/packaging/homebrew/voice-layer.rb" "$TAP_DIR/Formula/voice-layer.rb"

brew install --build-from-source voice-layer/local/voice-layer
voice-layer --version
voice-layer install --agent both --dry-run
voice-layer doctor --agent both
brew test voice-layer
brew uninstall voice-layer
brew untap voice-layer/local
```

The formula installs the CLI and skill resources only. It must not modify
`~/.claude`, `~/.agents`, or `~/.config`; users do that explicitly with
`voice-layer install`.

## Public tap conversion

The public tap repo should be `ymeiri/homebrew-voice-layer`, which users tap as
`ymeiri/voice-layer`.

After creating the v0.1.0 GitHub release, upload the exact archive generated by
`scripts/validate_release_archive.py`, then compute its checksum:

```sh
shasum -a 256 packaging/homebrew/dist/voice-layer-0.1.0.tar.gz
```

Copy `voice-layer.public.rb` into the tap repo as `Formula/voice-layer.rb` and
replace `__REPLACE_WITH_RELEASE_SHA256__` with that checksum.

Do not use a raw working-tree tarball for the public formula.
