# Brand Asset Provenance

`voice-layer` uses a text-transformation visual language: generic AI text passes
through a local profile layer and comes out as channel-shaped writing.

## Shipped Assets

- `assets/brand/logo.png` is the README logo selected from Nano Banana /
  Gemini exploration board option #7.
- `assets/brand/logo.svg`, `logo-mark.svg`, and `logo-dark.svg` are maintained
  SVG assets kept for package/icon compatibility.
- `assets/brand/readme-hero.svg` is a hand-authored README diagram.
- `assets/brand/readme-hero.png`, `social-preview.png`, and
  `demo-thumbnail.png` are rendered derivatives of the project hero asset.
- `assets/demo/voice-layer-demo.gif` is generated from a redacted Claude Code
  screen recording using synthetic demo data.

## Exploration Notes

Nano Banana / Gemini image generation was used only for logo direction
exploration. Rejected exploratory generations are not release artifacts. The
committed assets avoid audio, waveform, face, mascot, celebrity, biometric, and
voice-cloning metaphors.

Terms check on 2026-05-17: Google's public Terms of Service state that Google
does not claim ownership over original content generated in services that allow
users to generate content. Use remains subject to Google's terms and policies.
The committed release assets are project-maintained SVG/PNG/GIF artifacts, not
raw rejected generations.
